## 简介

琉璃启动器基于 Electron + React 开发，支持 Windows、macOS 和 Linux。它把游戏下载、模组加载器安装、社区资源、整合包、多人联机和个性化外观放在一个玻璃质感的界面里，面向国内网络环境做了镜像加速，安装后即可直接使用。

## 下载安装

在 [Releases](https://github.com/xiaoye1001/Liuli-Launcher/releases/latest) 页面下载对应系统的安装包：

| 系统 | 文件 | 说明 |
|---|---|---|
| Windows | `LiuliLauncher-Setup-<版本号>.exe` | 安装版，可选择安装位置并创建快捷方式 |
| Windows | `LiuliLauncher-Portable-<版本号>.exe` | 免安装版，游戏文件在 exe 旁边的 `.minecraft`，启动器文件在旁边的 `LiuliLauncher-Data` |
| macOS（Apple 芯片） | `LiuliLauncher-<版本号>-arm64.dmg` | 打开后拖入「应用程序」 |
| macOS（Intel） | `LiuliLauncher-<版本号>-x64.dmg` | 同上 |
| Linux | `LiuliLauncher-<版本号>.AppImage` | 添加执行权限后直接运行，需要 FUSE 2 |

运行游戏需要 Java：1.20.5 及以上需要 Java 21，1.18 ~ 1.20.4 需要 Java 17，1.17 需要 Java 16，更早的版本需要 Java 8。启动器可以自动下载合适的 Java。

> 安装包目前没有代码签名。Windows 首次运行如果提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」；macOS 首次打开请在「应用程序」中右键 →「打开」。

## 功能

### 游戏下载与安装
- 正式版、快照版、远古版列表，支持搜索；可选 **BMCLAPI 镜像** 或 **Mojang 官方源**，镜像失败时自动回退
- **新版本发布提醒**：Minecraft 出了新的正式版（可选：快照）时在主页提醒，一键打开安装设置
- 一键安装 **Forge**、**NeoForge**、**Fabric**、**Quilt** 和 **OptiFine**
- 多线程分块下载，支持取消、重试；已安装版本可以「检查并修复」
- 导入、导出 Modrinth（`.mrpack`）、CurseForge、MultiMC / Prism、MCBBS 格式整合包；从下载页安装的整合包支持 **一键更新**，保留存档和改过的配置

### 社区资源
- 同时搜索 **Modrinth** 与 **CurseForge**（CurseForge 通过 MCIM 镜像访问），下载模组、整合包、数据包、资源包和光影包
- 按游戏版本、加载器、分类筛选和排序；安装模组时自动安装前置模组
- 常用模组显示中文名，可以直接用中文名搜索

### 启动
- 自动选择或下载合适的 Java；按游戏版本、模组、光影和电脑内存 **自动分配内存**
- 启动前检查游戏文件，缺失或损坏时自动补全
- 分阶段的启动动画、实时日志窗口；游戏运行中可以一键结束游戏
- **崩溃分析**：用中文说明崩溃原因和解决办法，可一键分享日志到 [mclo.gs](https://mclo.gs/)；**崩溃记录** 记下每次崩溃和启动失败的时间、版本和原因
- **AI 助手**：填写自己的 API Key（支持 Claude，以及 DeepSeek、通义千问、Kimi、本机 Ollama 等 OpenAI 兼容接口），游戏崩溃或启动失败时自动分析原因并给出解决方法；Key 加密保存在本机，发送前去掉登录令牌等隐私信息
- **游戏打不开修复向导**：按步骤检查游戏文件、改为自动选择 Java、清除自定义启动参数、暂时禁用最近添加的模组、画质改成流畅
- 每个版本可以单独设置内存、Java、窗口大小、JVM 参数、启动前 / 退出后命令等；**启动参数预设** 一键选「自动 / 低配电脑 / 大型整合包 / ZGC 低停顿」，Java 太旧时不能选 ZGC
- **多开**：在主游戏之外同时再开几个游戏窗口（不同的离线名字），自己测试联机、同时挂两个号
- **游戏内设置**：一键切换画质档位（流畅 / 均衡 / 高画质），从其他版本复制设置或只复制按键，检查 **按键冲突**（一键解绑或全部恢复默认），修改前自动备份
- 支持多个游戏目录、版本隔离、版本收藏与自定义图标、游玩时长统计
- **继续游戏**：一键跳过主菜单直接进入上次玩的存档（1.20 及以上）；新版本第一次启动就是简体中文
- 显示每次的 **启动用时**，游戏运行时显示内存和 CPU 占用和 **变化曲线**
- **卡顿报告**：游戏结束后根据游戏日志和资源占用说说这次卡不卡（服务器跟不上、内存不足、连接超时、CPU 满载）和可以怎么办，有问题时主页提醒
- 系统托盘图标；健康游戏提醒（连续玩到设定时间时提醒休息）；启动器在后台时，下载、安装、更新完成会弹 **系统通知**

### 版本与存档管理
- 模组管理：启用 / 禁用、依赖检查、检查更新，一键打开模组的 **MC百科** 页面；更新后有问题可以 **退回旧版**，崩溃时提示退回最近更新的模组
- **模组冲突检测**：读取模组自己声明的不兼容（按版本范围判断），并提示常见冲突（例如 Sodium 和 OptiFine、两个光影加载器），一键禁用
- **模组兼容检查**：找出装错加载器、不支持当前游戏版本的模组，以及停用了还留着的旧版本，一键清理
- **模组二分排查**：游戏崩溃又不知道是哪个模组时，每轮只开一半模组，进游戏试一下回答「问题还在 / 消失了」，几轮后找到出问题的模组；自动带上前置模组，结束后恢复原样
- **模组更新提醒**：后台定期检查模组新版本，版本列表上直接显示「N 个模组可更新」
- **模组启用方案**：把哪些模组开、哪些关存成方案（例如「生存」「光影」），一键切换
- **模组版本迁移助手**：换新游戏版本时，检查模组在新版本上有没有，一键装过去
- **模组同步码**：把整个版本的模组变成一串同步码发给朋友，对方粘贴后一键装成一样的（模组来自 Modrinth，装之前自动拍快照）
- **模组配置编辑**：用表单改模组配置（TOML、JSON、.properties、Forge .cfg），显示取值范围和可选值，第一次修改前自动备份，可以还原
- **版本快照**：把模组、模组配置和游戏设置存一份，装坏了、更新坏了一键恢复；更新模组、整合包、一键优化等操作之前 **自动拍快照**，崩溃时可以一键回到快照
- 模组页 **一键性能优化**（Sodium、Lithium、FerriteCore 等）和 **一键模组汉化**（CFPA 的 I18nUpdateMod，进入游戏时自动更新汉化）
- **我的模组合集**：把常用的模组存成合集，一键装到别的版本（按版本自动选择合适的模组版本）
- 存档管理：备份与还原、导入、查看种子与游戏规则、管理数据包；**退出游戏后自动备份** 玩过的存档（每个存档保留最近 3 份），备份位置可以自己选
- **存档云备份（WebDAV）**：备份自动上传到自己的网盘（坚果云、Nextcloud、群晖等；**百度网盘、夸克网盘** 通过本机运行的 [OpenList](https://github.com/OpenListTeam/OpenList) / AList 挂成 WebDAV 后使用，设置页有一键预设和步骤说明），换电脑也能下载回来接着玩；网盘密码加密保存
- 存档的游戏统计（游玩时间、死亡次数、挖到的钻石等）、**存档地图预览**（主世界俯视图，可以拖动、缩放，鼠标指着显示坐标），一键打开种子地图或收藏种子
- **坐标笔记本**：给每个存档记坐标（基地、村庄、要塞），下界和主世界坐标自动换算，一键复制传送命令，记下的点显示在存档地图上
- **存档版本提示**：存档是更新的游戏版本存的、或者打开后会被升级时提醒先备份
- **存档体积和瘦身**：看主世界、下界、末地等各占多少空间；删掉几乎没去过、离出生点和玩家都远的区域，删之前先完整备份
- 资源包、光影包和游戏截图管理；截图可以 **按游玩整理**（每次游玩一组，标出那次玩的存档和服务器），一组截图可以拼成一张图分享；**一键光影**：自动装好 Iris / Oculus 和渲染优化模组，下载光影包并开启
- **投影文件管理**（Litematica）：列出 schematics 文件夹里的投影，查看大小、作者和 **材料清单**（游戏里的中文名、按组和潜影盒计算），一键复制清单

### 服务器与多人联机
- 收藏服务器，显示在线人数、延迟和 MOTD，点「加入」直接进入；打开 **上线提醒** 后，服务器上线或有人进服时弹通知
- 三种联机方式，都用一个房间码完成：**极速直连**、**P2P 组网**（基于 [EasyTier](https://github.com/EasyTier/EasyTier)）和 **内网穿透**
- **一键开服**：在自己电脑上开原版服务器（从 Mojang 官方下载服务端，需要你同意 Minecraft EULA），同一个局域网的朋友直接加入；可以看服务器输出、输入命令，点按钮管理在线玩家、管理员和白名单，退出启动器时自动保存并停止；一键生成 **联机房间码**，不在同一个局域网的朋友也能加入；可以给服务器 **添加数据包**，一键装 **Fabric 服务端** 和服务端模组（可以从客户端版本导入，自动跳过只能在客户端用的模组）

### 百宝箱小工具
- **种子收藏夹**：记下好玩的世界种子，支持文字种子，一键复制或打开种子地图
- **Minecraft 小工具**：下界 / 主世界坐标换算、区块坐标、游戏时间换算（一键复制 /time set 命令）
- **史莱姆区块查看**（Java 版）：输入种子，看坐标附近哪些区块会刷史莱姆，和游戏的算法一样
- **命令生成器**（Java 版）：填表生成给物品（附魔、名字）、状态效果、召唤生物、彩色文字的命令，按游戏版本自动用对应的写法
- **附魔计算器**：选物品和想要的附魔，算出铁砧上最省经验的合并顺序，每一步都不会「过于昂贵」（Java 版 1.21 及以后的规则和游戏数据）
- **红石计算器**：漏斗传输速度、熔炉 / 高炉烧炼时间和燃料、比较器信号强度、红石刻换算
- **版本差异对比**：比较两个版本（例如整合包更新前后）的模组和配置文件有什么不同
- **地图画生成器**：把图片换成地图上能显示的颜色，得到方块清单（按组和潜影盒计算），保存成 Litematica 投影照着摆
- **合成与交易查询**：直接读这个版本游戏文件里的配方，查一个物品怎么做、能用来做什么；还有原版村民的常见交易和工作站
- **插件**：在「更多 → 插件」安装别人做的 .zip 插件（也可以直接拖进启动器窗口），插件可以带一个 **主页小组件**，和最近游玩、新闻一起排位置，给启动器加小工具。插件运行在隔离的沙箱里，碰不到账号、登录令牌、密钥和电脑上的文件，安装前会列出它要的权限，同意后才安装；可以随时停用、清除数据或卸载。想自己做插件，看 [插件开发说明](docs/plugins.md) 和 [示例插件](docs/plugin-example/)

### 账号
- 离线账号、**微软正版账号**、外置登录（LittleSkin 等 authlib-injector 皮肤站）
- 3D 皮肤预览，正版账号可以直接更换皮肤和披风
- **皮肤衣柜**：保存多套皮肤，一键换上（离线账号直接换，正版账号自动上传）

### 界面与个性化
- 深色 / 浅色 / 跟随系统主题，多套主题方案和动态粒子背景
- 原创精选主题（高清壁纸与背景音乐）；自定义壁纸（图片或视频）、主题色、字体、界面缩放
- 背景音乐播放器、鼠标点击特效、Minecraft 官方新闻；主页闪烁标语和今日冷知识，游戏截图可以设为启动器背景；填了生日的话生日当天有惊喜
- 主页 **每日小目标**（每天一个游戏里的小挑战，连续打卡解锁成就）和 **那年今日**（往年的今天拍的游戏截图）
- **Ctrl+K 快速搜索**：输入关键字跳到页面、设置、工具和版本
- **自定义布局**：导航栏放左边、右边或顶部，自己排导航栏页面的顺序；主页的启动区放左边或右边，最近游玩、新闻、欢迎卡片自己排上下顺序，内容可以靠下或靠上
- **编辑页面布局**：设置、账号、版本设置、下载、服务器、联机、AI 助手、更多等页面点标题栏右边的「编辑布局」，拖动或用箭头排区块的顺序、隐藏不用的区块、选整行 / 左列 / 右列；每个页面单独保存，可以一键恢复默认
- **我的游玩报告**（每周游玩时长、最常玩的版本），可以生成 **年度报告图片** 保存或分享
- 23 个 **启动器成就**（包括隐藏成就），解锁时弹出「达成进度！」
- 自动检查更新，下载后校验签名并一键重启更新
- **启动前检查**：点启动时先看看内存是不是分配太多、模组适不适合这个版本、磁盘是不是快满了，有问题先提醒，可以直接启动或者先去处理
- 第一次打开时有 **新手引导**：几步设好名字、外观、下载源，装上第一个游戏
- **导出 / 导入设置**：把设置、我的主题、服务器、种子、模组合集、皮肤衣柜导出成一个文件，换电脑后一键恢复（不包含账号、密钥、密码和本机路径）

## 微软正版登录

启动器使用微软官方的设备代码登录：在微软官网输入启动器显示的代码即可完成登录，启动器不会接触你的账号密码。

- 支持添加多个微软账号并随时切换
- 登录凭证使用系统的安全存储加密保存，启动游戏时自动续期
- 登录后可以在账号页更换正版皮肤和披风

## 数据存放位置

游戏文件（版本、模组、存档、资源包）和启动器文件（设置、账号、缓存、Java、主题）分开存放：

| | 游戏文件 | 启动器文件 |
|---|---|---|
| 免安装版 | exe 旁边的 `.minecraft` | exe 旁边的 `LiuliLauncher-Data` |
| Windows 安装版 | `%APPDATA%\.minecraft` | `%APPDATA%\mc_launcher` |
| macOS | `~/Library/Application Support/minecraft` | `~/Library/Application Support/mc_launcher` |
| Linux | `~/.minecraft` | `~/.config/mc_launcher` |

安装版的游戏文件就在系统的 `.minecraft` 里，和官方启动器共用。在「设置 → 游戏目录」里可以添加其他游戏目录并随时切换。

「一键开服」创建的服务器（包括服务器的存档）放在启动器文件夹的 `local-servers` 里，皮肤衣柜放在 `skin-wardrobe` 里；版本快照放在版本游戏文件夹的 `liuli-snapshots` 里，投影文件（包括地图画）在版本游戏文件夹的 `schematics` 里，改模组配置前的备份在版本游戏文件夹的 `liuli-config-backup` 里；坐标笔记本保存在各个存档文件夹的 `liuli-waypoints.json` 里。

0.5.1 及以前的版本把游戏文件放在启动器文件夹里的 `.minecraft`，升级后第一次打开时会自动搬到上面的位置（只是改名，不复制、不删除）；新位置已经有 `.minecraft` 时保持原位置，在游戏目录列表里显示为「旧的默认目录」。

卸载时不会删除这些文件。

## 开发

### 环境要求
- [Node.js](https://nodejs.org/) 22.12 或更高版本

### 运行
```bash
git clone https://github.com/xiaoye1001/Liuli-Launcher.git
cd Liuli-Launcher
npm install
npm run dev
```

### 常用命令
| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发模式运行 |
| `npm run build` | 构建到 `out/` 目录 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run format` | 用 Prettier 格式化代码（`format:check` 只检查） |
| `npm run build:win` | 打包 Windows 安装版与免安装版 |
| `npm run build:mac` | 打包 macOS dmg（需要在 macOS 上运行） |
| `npm run build:linux` | 打包 Linux AppImage |

打包结果在 `dist/` 目录。正式版本由 GitHub Actions 的 Release 工作流自动构建并发布。

### 项目结构
```
src/
├── main/        # 主进程：下载安装、启动游戏、账号、模组管理等
├── preload/     # 预加载脚本：向界面暴露 window.api
├── renderer/    # 界面（React）
└── shared/      # 主进程与界面共用的类型和工具
```

## 技术栈

- [Electron](https://www.electronjs.org/) + [electron-vite](https://electron-vite.org/)
- [React 18](https://react.dev/) + TypeScript + [Tailwind CSS](https://tailwindcss.com/) + [Framer Motion](https://www.framer.com/motion/) + [Lucide](https://lucide.dev/)
- [@xmcl](https://github.com/Voxelum/minecraft-launcher-core-node)：游戏安装、启动、模组解析与登录
