常见问题

Windows 提示「Windows 已保护你的电脑」怎么办？

安装包没有代码签名，首次运行时 Windows 会提示。点「更多信息」→「仍要运行」即可。

安装版和免安装版有什么区别？

安装版会安装到电脑上，创建桌面和开始菜单快捷方式，数据保存在 %APPDATA%\mc_launcher。免安装版是单个 exe，双击直接运行，数据保存在 exe 旁边的 LiuliLauncher-Data 文件夹，整个文件夹复制到 U 盘就能带走。

macOS 提示「无法验证开发者」或「已损坏」？

没有 Apple 开发者签名。第一次打开时在「应用程序」中右键点「琉璃启动器」→「打开」。如果提示已损坏，在「终端」运行：

xattr -cr /Applications/琉璃启动器.app
macOS 该下载哪个？

点左上角苹果菜单 →「关于本机」：芯片显示 Apple M1、M2、M3、M4 等选「Apple 芯片」版本；显示 Intel 选「Intel 芯片」版本。

Linux 上无法运行 AppImage？

先添加执行权限：

chmod +x LiuliLauncher-*.AppImage
./LiuliLauncher-*.AppImage

需要 FUSE 2：Ubuntu 22.04 安装 libfuse2，Ubuntu 24.04 安装 libfuse2t64。提示沙盒错误时可以加 --no-sandbox 参数运行。

需要自己安装 Java 吗？

不需要。启动器会按游戏版本自动选择本机的 Java，没有合适的会自动下载（与官方启动器相同的 Java 运行环境）。

支持正版登录吗？账号安全吗？

支持微软正版登录，通过微软官方页面登录，启动器不会接触你的密码；登录凭据在本机加密保存。也支持离线账号和 authlib-injector 外置登录。

怎么校验下载的文件？

每个安装包下面都列出了 SHA-256 校验值，点一下就能复制。Windows 可以在 PowerShell 运行 Get-FileHash 文件名，macOS / Linux 运行 shasum -a 256 文件名 对比。
