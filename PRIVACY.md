# Privacy Policy / 隐私政策

[English](#english) | [中文](#中文)

## English

Liuli Launcher does not collect, sell or share any personal data. It has no analytics, telemetry, advertising or crash reporting, and the developer does not run any server that receives data from the launcher.

### Data stored on your computer

- Settings, the game directory, play history, backgrounds and music you add are stored locally in the launcher's data folder.
- Microsoft and external (authlib-injector) account tokens are stored locally and encrypted with the operating system's secure storage. Passwords for external accounts are only sent to the authentication server you choose and are never stored.
- Uninstalling the launcher does not delete this folder; you can delete it yourself at any time.

### Network connections

The launcher only connects to the services needed for the feature you are using:

| Service | When | What is sent |
|---|---|---|
| Microsoft, Xbox Live and Minecraft services | When you sign in with a Microsoft account or launch the game with it | The standard sign-in requests of Microsoft's device-code login |
| External authentication server chosen by you | When you sign in with an external account | Your user name and password for that server |
| authlib-injector download site (authlib-injector.yushi.moe) | When an external account is used for the first time | A download request only |
| Mojang / Minecraft servers, BMCLAPI mirror, Forge, NeoForge, Fabric and Quilt servers | When you browse or install game versions, loaders or Java | Download requests only |
| Modrinth and CurseForge (via a mirror) | When you search or download mods, resource packs, shaders or modpacks | Search terms and download requests |
| Minecraft news feed (launchercontent.mojang.com) | When the news panel is shown on the home page (can be turned off in Settings) | A download request only |
| GitHub, or the project website if configured | When checking for launcher updates (automatic check can be turned off in Settings) | A request for the latest version information |
| mclo.gs | Only when you click "Share log" | The game log, with account tokens and your user folder path removed |
| Servers you add | When you check their status or join them | Standard Minecraft protocol requests |

These services have their own privacy policies.

### Contact

Questions about privacy can be raised in the project's [GitHub issues](https://github.com/xiaoye1001/Liuli-Launcher/issues).

## 中文

琉璃启动器不收集、出售或分享任何个人数据。启动器没有统计、遥测、广告或崩溃上报，开发者也没有运行任何接收启动器数据的服务器。

### 保存在你电脑上的数据

- 设置、游戏目录、游玩记录，以及你添加的背景图片和音乐，都保存在启动器的数据文件夹里。
- 微软账号和外置登录（authlib-injector）账号的登录凭据保存在本地，并用操作系统提供的安全存储加密。外置登录的密码只发送给你选择的认证服务器，不会保存。
- 卸载启动器不会删除这个文件夹，你可以随时自行删除。

### 网络连接

启动器只在使用相应功能时连接所需的服务：

| 服务 | 什么时候 | 发送的内容 |
|---|---|---|
| 微软、Xbox Live 和 Minecraft 服务 | 登录微软账号、用微软账号启动游戏时 | 微软设备代码登录的标准请求 |
| 你选择的外置登录认证服务器 | 登录外置账号时 | 你在该服务器上的用户名和密码 |
| authlib-injector 下载站（authlib-injector.yushi.moe） | 第一次使用外置账号时 | 只有下载请求 |
| Mojang / Minecraft 服务器、BMCLAPI 镜像、Forge、NeoForge、Fabric、Quilt 服务器 | 浏览或安装游戏版本、加载器、Java 时 | 只有下载请求 |
| Modrinth、CurseForge（通过镜像） | 搜索或下载模组、资源包、光影、整合包时 | 搜索关键词和下载请求 |
| Minecraft 新闻（launchercontent.mojang.com） | 主页显示新闻时（可以在设置里关闭） | 只有下载请求 |
| GitHub，或配置了的项目官网 | 检查启动器更新时（自动检查可以在设置里关闭） | 获取最新版本信息的请求 |
| mclo.gs | 只在你点击「分享日志」时 | 游戏日志（已去掉账号令牌和你的用户文件夹路径） |
| 你添加的服务器 | 查看服务器状态或进入服务器时 | 标准的 Minecraft 协议请求 |

这些服务有各自的隐私政策。

### 联系

关于隐私的问题，可以在项目的 [GitHub Issues](https://github.com/xiaoye1001/Liuli-Launcher/issues) 中提出。
